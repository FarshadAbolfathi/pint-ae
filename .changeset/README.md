# Changesets

This folder has been automatically generated by `@changesets/cli`, a tool that
manages versioning and changelogs with a focus on monorepos.

Add a changeset for any user-facing change:

```sh
pnpm changeset
```

See the [Changesets docs](https://github.com/changesets/changesets) for details.
Publishing to npm is **not** enabled yet (see the roadmap in the root README).
